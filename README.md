# 🛒 Amazon Clone – Frontend Project

A **fully responsive** clone of the Amazon homepage built using only **HTML** and **CSS**.  
This was my **first project**, created under the guidance of **Apna College**, to strengthen my understanding of frontend development.

> 🚀 **Live Demo**: [View the Project]([https://yourusername.github.io/amazon-clone/](https://dileepkumarrambarki.github.io/Amazon-clone-/Amazon-clone.html#))  
> 🎓 Guided by: [Apna College](https://www.youtube.com/c/ApnaCollegeOfficial)

---

## 📌 Project Overview

The goal of this project was to replicate the **Amazon home page UI** using basic web development tools.

- 📱 Fully responsive design for mobile, tablet, and desktop
- 🧱 Layout built with Flexbox
- 🖼️ Multiple reusable components (nav bar, hero section, product cards, footer)
- 🔍 Hover effects and transitions for a real Amazon-like feel

---

## 🛠️ Tech Stack

- **HTML5** – For page structure  
- **CSS3** – For styling, layout, and responsiveness

---

## 🎯 What I Learned

- Semantic HTML structure  
- CSS Flexbox and layout techniques  
- Media queries for responsiveness  
- Building components like headers, footers, product cards  
- Hosting static sites using GitHub Pages
